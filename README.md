# Расписание классов

Многостраничный сайт с расписанием уроков для 5–11 классов.

**Возможности:**
- Главная страница с выбором класса
- Отдельная страница для каждого класса (5–11)
- Навигация по дням недели внутри страницы
- Плавная прокрутка к нужному дню

**Технологии:** HTML, CSS

**Смотреть:** https://minakmin29-tech.github.io/High-School-Schedule/
